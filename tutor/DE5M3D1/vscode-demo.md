## VS Code demo: edit and run a script

- Share screen - learners watch, they do it themselves in the next block
- Terminal: cd into M3, then `code .` - always open the M3 folder, so the VS Code terminal starts there
- Explorer: open day1/stretch/etl_solution.py and walk through the functions
- Make a small edit (e.g. a print message), save with Ctrl+S
- Open the VS Code terminal (Ctrl + backtick) and run `python day1\stretch\etl_solution.py` - show the edit in the output
